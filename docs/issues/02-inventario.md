# Implementar sistema de inventario

Labels sugeridas: `inventario`, `gameplay`

## Descricao

Criar uma estrutura de dados para armazenar os itens coletados por Arya, permitindo adicionar, remover e consultar itens durante o jogo.

## Criterios de aceitacao

- [x] Inventario armazena itens coletados
- [x] Possui operacao de adicionar item
- [x] Possui operacao de remover item
- [x] Possui operacao de consultar existencia de item
- [x] Possui contagem por nome de item
- [x] HUD exibe quantidade de galhos coletados
- [x] Tela de inventario abre e fecha com `L`

## Problema computacional

Estrutura de dados de lista com operacoes de insercao, remocao, consulta, contagem e filtro.

## Justificativa

O inventario e necessario para que a coleta tenha persistencia e para que o jogador acompanhe seu progresso.
