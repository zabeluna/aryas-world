# Ordenar inventario com QuickSort

Labels sugeridas: `algoritmo`, `inventario`

## Descricao

Usar QuickSort para manter os itens do inventario ordenados por nome, facilitando exibicao e consulta.

## Criterios de aceitacao

- [x] Inventario chama QuickSort apos adicionar item
- [x] Algoritmo ordena strings por ordem alfabetica
- [x] Tela de inventario exibe itens agrupados por nome
- [x] Documentacao explica o papel do QuickSort como segundo problema computacional

## Problema computacional

Ordenacao por QuickSort.

## Justificativa

O QuickSort e um algoritmo classico de ordenacao e esta integrado ao gameplay porque organiza os itens realmente coletados pelo jogador.
